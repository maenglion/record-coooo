1. 프로그램 기본 사용법
--------------------------------------------------
[디스코드 봇 (스마트폰 연동용)]
- 켤 때:
  1) PowerShell 또는 명령 프롬프트를 엽니다.
  2) 아래 2줄을 실행합니다.
     cd c:\recording_insta\record-coooo
     python bot_discord.py
  3) 메모장에 보관해 둔 디스코드 봇 토큰을 붙여넣고 Enter를 누릅니다.
  4) 스마트폰 디스코드 앱의 '#일반' 채널(또는 내 서버)에
     인스타/트위터/유튜브/틱톡/스레드 링크를 보내면 영상이 답장으로 옵니다.
  5) 스마트폰에서 영상을 길게 눌러 '동영상 저장'을 누르면 갤러리에 저장됩니다.

- 끌 때:
  봇이 실행 중인 PowerShell 창을 클릭하고 [Ctrl + C] 를 누르면 정상 종료됩니다.

[PC 직접 다운로드 (터미널용)]
- 봇 없이 PC에서 직접 특정 폴더로 저장하고 싶을 때:
  cd c:\recording_insta\record-coooo
  python downloader.py
  -> 링크 입력 후, 저장하고 싶은 폴더 경로(예: D:\영상)를 입력하면 됩니다.

- 파일 저장 위치:
  기본적으로 c:\recording_insta\record-coooo\downloads 폴더에 원본이 자동 보관됩니다.


2. 약점 대비 및 유지보수 방법
--------------------------------------------------
[약점 1] SNS 플랫폼의 주소 체계 변경 및 차단 정책
- 원인: 인스타그램, 스레드, 트위터(X) 등은 몇 달에 한 번씩 영상 전송 방식이나
        봇 차단 정책을 업데이트합니다.
- 증상: 평소 잘 되던 링크가 갑자기 다운로드 실패 에러를 뱉는 경우.
- 해결법: PowerShell 창에서 아래 엔진 최신 패치 명령어 1줄만 실행하면
          90% 이상 즉시 해결됩니다.
  
  pip install --upgrade yt-dlp yt-dlp-threads

[약점 2] 디스코드 25MB 전송 한도
- 원인: 디스코드 무료 봇의 파일 전송 한도는 25MB입니다.
- 증상: 10분이 넘는 긴 유튜브 영상 등은 스마트폰 채팅방으로 직접 오지 않습니다.
- 보완: 이 경우에도 내 PC의 downloads 폴더에는 최고 화질 원본이 온전히 저장되며,
        봇이 '25MB 초과로 PC에 저장되었습니다'라는 안내 메시지를 남깁니다.
        (릴스, 쇼츠, 트위터, 틱톡 영상은 99% 25MB 이내이므로 정상 전송됩니다.)

[약점 3] PC 구동 의존성
- 봇은 내 PC가 켜져 있고 코드가 돌아가는 동안에만 스마트폰에서 응답합니다.
  (PC를 끄면 봇은 오프라인 상태가 됩니다.)


3. 자주 발생하는 오류 및 대처
--------------------------------------------------
- PrivilegedIntentsRequired 오류:
  디스코드 개발자 포털(discord.com/developers/applications)의
  [Bot] 탭에서 'MESSAGE CONTENT INTENT' 스위치를 켜고
  [Save Changes]를 눌렀는지 확인 후 다시 실행합니다.

- ffmpeg 관련 합병 오류:
  pip install imageio-ffmpeg 실행

- 스레드 영상만 안 따지는 오류:
  pip install yt-dlp-threads 실행

- 새 코드나 패치를 깃허브에서 가져올 때:
  cd c:\recording_insta\record-coooo
  git pull


4. 향후 필요할 때 업그레이드할 수 있는 선택지
--------------------------------------------------
1) 더블클릭 실행기:
   매번 토큰 치고 명령어 칠 필요 없이, 바탕화면 아이콘 더블클릭 1번에
   봇이 켜지는 바로가기 파일(.bat) 제작

2) 24시간 클라우드 상주:
   내 PC를 꺼도 24시간 스마트폰에서 작동하도록
   무료 클라우드 서버(Railway 등)에 봇 올리기

3) 대용량 영상 자동 압축:
   25MB 넘는 영상도 스마트폰으로 받을 수 있도록
   자동 리사이즈(용량 압축) 기능 추가


5. 24시간 무료 클라우드(Render) 배포 가이드
--------------------------------------------------
내 컴퓨터를 꺼도 봇이 24시간 돌아가게 하는 검증된 완전 무료 루트입니다.
(신용카드 불필요, 월 750시간 무료 = 24시간 365일 상주 가능)

[1단계] Render 가입
- render.com 접속 -> [Get Started for Free] 클릭
- [GitHub] 버튼으로 1초 로그인

[2단계] 저장소 연결
- Render 대시보드 우측 상단 [New +] -> [Web Service] 클릭
- [Build and deploy from a Git repository] 선택 -> [Next]
- GitHub 계정 연결 후 'maenglion/record-coooo' 저장소 선택 -> [Connect]

[3단계] 서비스 설정 (대부분 자동 입력됨)
- Name: video-discord-bot (아무 이름)
- Region: Singapore 또는 Oregon
- Runtime: Python 3
- Build Command: pip install -r requirements.txt
- Start Command: python bot_discord.py
- Instance Type: Free (512MB RAM) 선택

[4단계] 봇 토큰 비밀번호 등록
- 같은 페이지 아래 [Environment Variables] 섹션에서
  Key:   DISCORD_TOKEN
  Value: (메모장에 복사해 둔 봇 토큰 문자열)
- 페이지 맨 아래 [Create Web Service] 클릭!

[5단계] 잠들지 않게 무료 모니터(UptimeRobot) 연결 (가장 중요)
- Render 무료 플랜은 15분간 접속이 없으면 잠듭니다.
- 봇이 내장 헬스체크 주소를 갖고 있으므로, 무료 핑 서비스를 붙입니다.
- uptimerobot.com 접속 -> 무료 가입 -> [Add New Monitor]
  * Monitor Type: HTTP(s)
  * Friendly Name: 내 디스코드 봇
  * URL (or IP): https://내서비스이름.onrender.com
  * Monitoring Interval: 5분
  * [Create Monitor] 클릭
- 이제 5분마다 Render를 쿡 찔러주므로 절대 잠들지 않고 24시간 동작합니다.

[주의 한계점]
- Render 무료 RAM은 512MB입니다. 인스타 릴스/트위터/쇼츠 영상(200MB 이하)은
  안정적으로 합체되지만, 30분짜리 4K 영상 등 초고화질 대용량 변환 시
  일시적인 메모리 부족(OOM)으로 프로세스가 재시작될 수 있습니다.
- 25MB 전송 한도는 디스코드 자체 정책이므로 클라우드에서도 동일하게 적용됩니다.


[2026.11 업데이트] 25MB 초과 영상 자동 압축 기능
--------------------------------------------------
- 원본 영상이 25MB를 초과하면 봇이 자동으로 재생시간을 분석하여,
  23MB 이하로 재인코딩(libx264+aac, 해상도 자동 조절)한 후 디스코드로 전송합니다.
- 압축본은 디스코드 전송 직후 임시 파일이 자동 삭제되며,
  최고 화질 원본은 downloads 폴더에 그대로 보존됩니다.
- 10~20분 이상의 매우 긴 영상의 경우 화질이 저하될 수 있으며,
  압축에는 영상 길이에 따라 30초~2분 정도 소요됩니다.
